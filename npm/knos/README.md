# knos

Proves a paper's claim on NEAR testnet from your terminal, with test money.

    npx knos@latest

It prints the claim, the sha256 of the test NEAR locked before any agent started, the verdict and the receipt's NEAR
transactions. Give a paper link and an amount of test USDC to prove another claim:
`npx knos@latest https://arxiv.org/abs/1406.2294 3`. MIT licensed: https://github.com/drexthealpha/Knos
