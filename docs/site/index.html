LOCAL-FIRST · ONE SQLITE FILE · NO SERVER

One memory every coding agent on your machine shares.

Two agents, or two people, change the same thing without knowing it. Knos is the record of who is on what — and it refuses to answer about work somebody else has taken, refuses the edit before the write lands, and refuses the purchase an unreliable agent asks for.

$ pip install "git+https://github.com/drexthealpha/Knos"
$ knos demo

Python 3.10+, git, a repository with at least one commit. It builds a throwaway repo, runs every refusal on it with the store present, deletes the store, and shows each one stop. About fifty seconds warm, ninety cold.

What it refuses

Three refusals. All three are reads of one file.

A claim is written once. Everything else Knos does is a decision made by reading it back. Delete the file and every one of these becomes “go ahead.”

The answer is withheld

A second agent asking about claimed work gets no answer at all — not an answer with a warning attached. It is told who holds it, how long the hold has left, and that an override costs a reason written in the journal under its own name.

The edit is refused before the write

A pre-tool hook in Claude Code, Cursor and OpenCode reads the same claim and exits 2. The other agent’s write never reaches the disk. Renaming the file does not get past it.

src/knos/guard.py · test_guard.py

The purchase is refused

Before real USDC moves on Base, the gate reads the agent’s record: claims taken against claims closed. An agent that abandons its work is refused. One that already bought this is served free. Nobody pays twice.

Local-first, and that is a test

There is no hosted Knos, and there will not be one.

The store is one SQLite file under ~/.knos/, written through Sibyl Memory. Nothing on the read path opens a socket.

  • No network on the read path. test_no_network.py breaks socket.connect, then reads a repo, answers, claims, withholds and overrides.
  • No account, no key, no server. The MCP server is launched by your editor over stdio.
  • Delete the file, and everything stops. test_sibyl_is_load_bearing.py removes it and asserts the withhold, the guard and the gate all revert.
  • The only things that ever leave the machine are the x402 payment and the ACP job — both opt-in, both on Base, both listed above.
$ rm ~/.knos/*/memory.db

$ knos ask "the guard"
It answers.          the withhold is gone

$ edit src/knos/guard.py
The edit lands.      the hook has nothing to read

$ knos who
Nobody has claimed anything here yet.

Three ways in

None of them a server you have to run.

Take it in whichever shape you already wanted. The commands are the ones in the README.

The Action

Zero install for the repo. Reads the committed .knos/decisions.md and comments on a pull request that touches claimed work. Exits 0 on every path.

- uses: drexthealpha/Knos/action@v0.1.8

The library

If you already ship a tool, import the claim. No MCP, no process, seven tests and no network.

from knos.core import Claims

with Claims(repo, who="my-agent",
            session=sid) as c:
    took, holder = c.take("the parser")

The server

If you already run several agents. Four tools — search, about, remember, done — over stdio.

pip install "git+https://github.com/drexthealpha/Knos"
knos connect      # Claude Code, Cursor, Desktop
knos guard --install   # off by default

Listed in awesome-mcp-servers. Also on PyPI as the last cut release, which trails main.
