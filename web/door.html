How it works
  1. It counts how many different lines your list holds. It does not say which items repeat or how often.
  2. Your list goes to Knos's server, which counts it and keeps it with its result page, so the link works. A sample result can be opened by anyone. Your own list can be opened only by people who have its link, and it is never listed. The server keeps results only until it is next rebuilt, so a link can stop working.
  3. The test that showed it works had to count 30,000 visitors within 10%, in at most 1.5 kilobytes. It did not check counts beyond 30,000 visitors, or the paper's 2% figure for very large lists.
  4. Runs on the sample are free. Runs on your own list: 5 free a day, then 20 more runs for $1 in test money. Today nothing is charged.
  5. It comes from a 2007 paper: HyperLogLog, by Flajolet, Fusy, Gandouet and Meunier.
  6. It depends on Knos's one server. When nobody has used it for a while it sleeps, and the first run is slow while it wakes.
