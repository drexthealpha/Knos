How it works
  1. The sample is made up: a straight line from 1.86 to 1.29 over 168 cycles, because NASA's page offers no download from a nasa.gov address. Its limit, 1.4, is the end-of-life rule on NASA's battery data page.
  2. It checks one column against one limit. It does not judge whether the limit is the right one. A row whose value is not a number is skipped and counted.
  3. Your file goes to Knos's server, which checks it and keeps it with its result page, so the link works. A sample result can be opened by anyone. Your own file can be opened only by people who have its link, and it is never listed. The server keeps results only until it is next rebuilt, so a link can stop working.
  4. The test that showed it works checks six made-up files with known answers and the sample. It did not cover files longer than 168 rows, or files separated by anything other than commas. The test is public.
  5. Runs on the sample are free. Runs on your own file: 5 free a day, then 20 more runs for $1 in test money. Today nothing is charged.
  6. Who built it: AI helpers write the program through Knos, and it is released only when that test passes. It has not been released yet.
