The same proof check, inside a lab: InterSystems IRIS

In IRIS, an AI Hub agent reads each test result and can only say no (with no model key, a rules referee does); a rule decides pass or fail; above $50 a person must also say yes. It runs inside the lab's own data system (InterSystems IRIS).

Install it

Docker with about 4 GB free and the IRIS image from InterSystems' AI Hub early access, then four commands:

git clone https://github.com/drexthealpha/Knos && cd Knos/iris
bash scripts/load-image.sh ~/Downloads/irishealth-community-2026.3.0AI.154.0-docker.tar.gz
bash scripts/env-secrets.sh && docker compose up -d --build
bash scripts/ready.sh

Then open http://localhost:52773/knos/ and press A passing test, $20: the decision appears in a few seconds.
