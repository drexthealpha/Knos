The ten-second check

Built 14 Sep to 12 Oct 2026 for Colosseum (tag v0.3.28).

What the check reads
  • Reads the pull request's description on GitHub.
  • Reads the checks GitHub ran on its last commit.
  • Says whether a test, build, lint or type check failed.
  • Asks GitHub alone, 60 reads an hour per address.
  • Sends nothing to Knos. Needs no sign-up.

Pay an agent only when its checks pass

Comment on an issue to post the task, its checks and the pay: /knos fund 20 checks: test. The pay waits in Knos's programs on Solana devnet, not with Knos. GitHub signs which checks ran on which commit; the program checks that signature before it pays, and a failed check pays nobody.

To be paid, comment your address on your own pull request: /knos address YOUR_SOLANA_ADDRESS. It is paid once the pull request is merged and GitHub has signed the run that pays it.

  • knos_oidc: verifies the token GitHub signs for a workflow run.
  • knos_pay: holds the pay and releases it only when every funded check passed.
  • knos_meter: counts each time a buyer's tests judge a piece of work.
  • knos_passkey: a wallet from a passkey.

Install with one pull request

Add one workflow file, .github/workflows/knos.yml; it needs no secret and no wallet. The second file, .github/workflows/knos-check.yml, adds the check on every pull request and is optional. The install steps at the tag.
