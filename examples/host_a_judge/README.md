# Host a judge

1. [Make the repository](https://github.com/new?template_owner=drexthealpha&template_name=knos-attest&name=knos-judge&visibility=public&owner=@me) in your own account. It holds one file, [`knos-attest.yml`](../knos-attest.yml), and needs no secret, wallet or key. (A repository you have already: `python -m knos.host_judge editor owner/name` prints the link that opens GitHub's editor with the file filled in.)
2. The buyer names it when funding: `/knos fund 20 checks: unit quorum 2 judge: <you>/knos-judge`. An order funded without `judge:` and without `neutral off` takes your run too.
3. After the merge: **Actions > knos attest > Run workflow**, with the pull request's repository, its number, the order's address, and `pay`.

- **What the receipt then reads.** `rerun` when you are not paid by the order and it is paid by an acceptance suite: your run fetched the two commits and ran that suite itself. `agreed` when a second host with another owner did the same. `reported` when you are a payee, when the terms declare you one party with a payee, or when the order is paid on the merge (nothing to run). The order's own repository never raises the level. `python -m knos.host_judge level --payee ID --host ID` says which, from account ids.
- **What you are paid.** Nothing by the order: the program has no judge's share. If you also run `knos relay` with your own fee payer and yours is the transaction that pays, you get the relayer's tip: 0.05 test USDC out of the fee, 0.30 when it creates a payee's token account.
- **What you can do.** Start the run or not (a quorum that names you is then refunded at its deadline), spend your repository's Actions minutes on the suite ([free on standard runners in a public repository](https://docs.github.com/en/billing/concepts/product-billing/github-actions)), delete the repository.
- **What you cannot do.** Get anything signed that GitHub's public record does not support (the run is Knos's workflow at the commit the order pinned), change who is paid or the terms, touch the money, or count twice with two repositories. On Solana devnet, in test USDC. No outside account has hosted a judge yet: `tests/test_host_a_judge.py` shows both levels, with two owners, in a simulator.
