# Host a referee
A referee is a GitHub repository of yours that runs a work order's checks again and asks GitHub to sign the result.
1. [Make an empty repository](https://github.com/new?name=knos-judge&visibility=public&owner=@me) in your own account and add its one file, [`knos-attest.yml`](../knos-attest.yml) (the same as [`templates/knos-attest`](../../templates/knos-attest)), as `.github/workflows/knos-attest.yml`: `python -m knos.host_judge editor <you>/knos-judge` prints the link that opens GitHub's editor with it filled in. It needs no secret, wallet or key.
2. The buyer names it when funding: `/knos fund 20 checks: unit quorum 2 judge: <you>/knos-judge`. An order funded with neither `judge:` nor `neutral off` also accepts your run.
3. After the merge: **Actions > knos attest > Run workflow**, with the pull request's repository, its number, the order's address, and `pay`.

- **What the receipt then reads.** `rerun`: your run fetched the two commits and ran the order's acceptance suite itself (only when the order is paid by that suite and does not pay you). `agreed`: a second host with another owner did the same. `reported`: you are a payee, the terms declare you one party with a payee, or the order is paid on the merge alone (nothing to run). The order's own repository never raises the level. `python -m knos.host_judge level --payee ID --host ID` tells you which, from account ids.
- **What you are paid.** Nothing by the order: the program has no referee's share. If you also run `knos relay` with your own fee payer and yours is the transaction that pays, you get the relayer's tip: 0.05 test USDC out of the fee, 0.30 when it creates a payee's token account.
- **What you can do.** Start the run or not (a quorum that names you is then refunded at its deadline), spend your repository's Actions minutes on the suite ([free on standard runners in a public repository](https://docs.github.com/en/billing/concepts/product-billing/github-actions)), delete the repository.
- **What you cannot do.** Get anything signed that GitHub's public record does not support (the run is Knos's workflow at the commit the order pinned), change who is paid or the terms, touch the money, or count twice with two repositories. On Solana devnet, in test USDC. No outside account has hosted a judge yet: `tests/test_host_a_judge.py` shows both levels, with two owners, in a simulator.
